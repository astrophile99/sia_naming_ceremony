# Music Folder

Place your ambient/lullaby audio file here:
- `lullaby.mp3`

Recommended: A soft, royalty-free lullaby or ambient instrumental.

Free sources:
- https://freemusicarchive.org (search "lullaby")
- https://pixabay.com/music (search "lullaby" or "baby")
- https://www.zapsplat.com

The music player will gracefully handle missing audio (no errors shown to users).
